# Contributing

Local Web Fix is a published portfolio concept. Changes should keep that clear and should not make the project look like an active client service.

1. Create a branch from `main`.
2. Run `npm install` and `npm test`.
3. Keep dependencies at zero unless there is a clear reason to add one.
4. Check the mobile layout, keyboard navigation, focus visibility and both colour themes.
5. Do not add testimonials, client names, results or guarantees unless they are real and can be evidenced.
6. Do not add live payment links or forms that collect real enquiries while the project is presented as a concept.

Use UK English, short paragraphs and plain language. Keep the JavaScript small and only add it where an interaction needs it.
